## 置き場のルール

- ここに置くのは **設計判断** (なぜこうしたか、却下した代替案) と **操作手順** (どう実行するか) の 2 種類だけ。
- **現状の記述は置かない**。スキーマ図・API 一覧・依存関係は手書きの写しが必ずずれるので、コードと migration を唯一の出典にする。
- 単一ファイルに閉じる判断はコード内のコメントと commit message に残す。複数ファイル・複数サービスにまたがるものだけをここに書く。
- 現行でなくなった文書は削除せず `archive/` へ移し、冒頭に移行注記を付ける。
